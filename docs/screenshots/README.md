## 采集说明

- **浏览器**：Playwright 自动化，1920×1080 视口
- **截图模式**：fullPage（完整页面滚动截图）
- **弹窗截图**：点击按钮触发弹窗后等待 2-3 秒再截图
- **下拉框截图**：点击下拉框展开选项后截图，再按 Escape 关闭
- **插件页面**：通过 Wujie 微前端 iframe 加载，URL 格式 `/plugin/l4d2/{menuPath}?instanceId=55&...`
- **登录页**：当前会话已登录，登录页截图来自退出登录流程
