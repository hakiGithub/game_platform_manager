## 注意事项

- **容器内 127.0.0.1 不是 WSL 主机**：添加主机请填 WSL 的 eth0 IP（`wsl hostname -I` 首个地址，重启可能变化），或在部署编排 backend 服务加 `extra_hosts: ["host.docker.internal:host-gateway"]` 后使用 host.docker.internal。
- **插件加载**：镜像不含插件，依赖挂载目录注入；`deploy-image.sh` 会自动同步 jar。
- **RCON 密码**：retag 镜像无法注入 SRCDS_RCONPW，换图等 RCON 操作的最终回显受此限制（网络可达官方镜像后自动恢复）。
