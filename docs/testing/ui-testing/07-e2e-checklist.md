# 07 - E2E 验证清单

> 发版前/日常验证的手动 + 半自动 E2E 清单

---

## 1. 使用说明

- **执行频率**：每次发版前必跑，重大修改后建议跑
- **执行方式**：通过 TRAE `browser_use` 子代理执行，或人工浏览器验证
- **通过标准**：所有 ✅ 项必须通过；⚠️ 项尽量通过；📋 项可选
- **失败处理**：记录失败步骤、截图、错误信息，提 issue 修复后重跑

## 2. 环境准备

### 2.1 验证账号（默认初始账号）

> 来源：`backend/core/src/main/resources/db/data.sql` 首次启动自动初始化。

| 字段 | 值 | 说明 |
|------|----|------|
| 用户名 | `admin` | 系统管理员 |
| 密码 | `admin123` | 初始密码（SHA256 加密存储） |
| 登录端点 | `POST /api/auth/login` | 返回 JWT Token |

**curl 登录示例：**
```bash
curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'
```

> ⚠️ 删除 `backend/data/game_platform.db` 后重启会自动重建该账号；生产环境请立即改密。

### 2.3 启动后端 + 前端 + 插件

```powershell
# 在项目根目录执行
.\scripts\rebuild-restart-all.ps1
```

脚本依次执行：停止旧后端 → 编译后端 → 打包插件 JAR → 部署到 `backend/plugins/` → 启动后端（等待 8080 端口 + 登录接口就绪）→ 停止旧前端 → 启动前端（3000 端口）。

**常用参数：**
- `-SkipBackendCompile`：跳过后端编译（仅改前端时使用）
- `-SkipPlugins`：跳过插件 JAR 打包（仅改后端代码时使用）
- `-SkipFrontend`：跳过前端启动
- `-FrontendPort 3001`：指定前端端口（默认 3000）

### 2.4 重启操作速查

测试过程中按需重启的常用命令（详细说明见 [02-toolchain.md §5.6](./02-toolchain.md)）：

| 场景 | 命令 |
|------|------|
| 全栈编译并重启 | `.\scripts\rebuild-restart-all.ps1` |
| 仅改后端 Java 代码 | `.\scripts\rebuild-restart-all.ps1 -SkipPlugins` |
| 仅改前端代码 | `.\scripts\rebuild-restart-all.ps1 -SkipBackendCompile -SkipPlugins` |
| 仅改插件代码 | `.\scripts\rebuild-restart-all.ps1`（含插件打包） |
| 仅改后端配置文件 | `cd backend; .\scripts\rebuild-restart.ps1 -SkipCompile` |
| 仅重启前端 | `cd frontend; .\scripts\rebuild-restart.ps1` |
| 停止后端 | `Get-NetTCPConnection -LocalPort 8080 -State Listen \| ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }` |
| 停止前端 | `Get-NetTCPConnection -LocalPort 3000 -State Listen \| ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }` |
| 实时查看后端日志 | `Get-Content backend/logs/application.log -Wait -Tail 50` |
| 实时查看前端日志 | `Get-Content frontend/logs/frontend.log -Wait -Tail 50` |

> 测试过程中如遇 8080/3000 端口未释放，等待 5-10 秒后重试；脚本内部已包含端口释放等待逻辑。
