**文档版本**：V1.0
**更新日期**：2026年03月22日
**适用范围**：全平台页面、插件页面

## 一、设计基础规范

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| Element Plus优先 | 所有组件、交互、样式必须以Element Plus官方设计规范为基础 |
| CSS变量驱动 | 全局主题色、圆角、间距、字体必须通过CSS变量定义 |
| 卡片式布局 | 内容区统一使用卡片式设计，保证视觉一致性 |
| 状态可视化 | 核心状态使用「颜色+图标+文字」三重标识 |
| 安全兜底 | 所有危险操作必须有二次确认 |

### 1.2 分辨率适配

| 分辨率 | 适配策略 |
|--------|----------|
| 1920*1080 | 默认设计基准，完整展示所有内容 |
| 1366*768 | 自动调整栅格占比，隐藏非核心表格列，保证核心功能可用 |

| 断点名称 | 宽度范围 | 说明 |
|----------|----------|------|
| xs | <768px | 不适配，提示使用更大屏幕 |

| md | >=992px | 最小支持分辨率1366*768 |
| lg | >=1200px | 标准分辨率1920*1080 |
| xl | >=1920px | 大屏分辨率 |

### 7.2 适配策略

```css

  display: none;
```

## 九、插件页面规范

### 9.1 强制规范

1. **禁止引入第三方UI库**：插件必须100%使用Element Plus组件
2. **禁止自定义全局样式**：必须复用主应用CSS变量
3. **禁止修改原生组件样式**：必须保持与主应用一致
4. **必须使用全局方法**：弹窗、通知、加载态必须使用主应用封装方法

### 9.2 插件插槽样式继承

```css
/* 插件内容自动继承主应用样式 */
.plugin-slot {
  /* 继承全局字体 */
  font-family: var(--el-font-family);
  font-size: var(--platform-font-size-base);
  color: var(--el-text-color-regular);

  /* 继承全局间距 */
  padding: var(--platform-card-padding);
}

/* 插件卡片样式 */
.plugin-card {
  background: var(--el-bg-color);

  box-shadow: var(--platform-card-shadow);
```
