## 一、全局交互规范

### 1.1 操作反馈规范

#### 1.1.1 同步操作反馈

| 操作类型 | 成功反馈 | 失败反馈 |
|----------|----------|----------|
| 表单提交 | Message成功提示，3秒自动消失 | Notification常驻提示，显示错误原因 |
| 状态切换 | Message成功提示，状态实时更新 | Notification常驻提示，显示错误原因 |
| 数据删除 | Message成功提示，列表自动刷新 | Notification常驻提示，显示错误原因 |

**Message提示规范**：
```javascript
// 成功提示
ElMessage.success('操作成功')

// 失败提示（简单错误）
ElMessage.error('操作失败：网络错误')
```

**Notification提示规范**：
```javascript
// 复杂错误，需要详细说明
ElNotification({
  title: '操作失败',
  message: '部署实例失败：主机离线，无法建立SSH连接',
  type: 'error',
  duration: 0 // 常驻，需手动关闭
})
```

#### 1.1.2 异步操作反馈

| 操作类型 | 进度反馈 | 完成反馈 |
|----------|----------|----------|
| 游戏部署 | 全局进度条 + 阶段文字 | 弹窗提示成功/失败 |
| 文件上传 | 单文件进度条 | Message提示 |
| 备份操作 | 进度条 + 百分比 | Message提示 |
| 大文件下载 | 下载进度条 | 无提示（浏览器处理） |

**部署进度反馈规范**：
```
+------------------------------------------------------------------+
|  部署进度                                                        |

|  | 45%                                                        |  |
```

**部署阶段说明**：

| 阶段 | 进度范围 | 说明 |
|------|----------|------|
| 环境准备 | 0-10% | 检查主机环境、安装依赖 |
| 依赖安装 | 10-30% | 安装必要依赖包 |
| 资源下载 | 30-60% | 下载游戏服务端文件 |
| 部署配置 | 60-80% | 生成配置文件、创建目录 |
| 启动实例 | 80-95% | 启动游戏服务端进程 |
| 健康检查 | 95-100% | 检查服务是否正常运行 |

### 1.2 按钮状态规范

#### 1.2.1 按钮状态定义

| 状态 | 视觉表现 | 交互行为 |
|------|----------|----------|
| 默认 | 正常样式 | 可点击 |
| 悬停 | 背景色加深 | 鼠标指针变为手型 |
| 点击 | 背景色再加深 | 触发点击事件 |
| 加载中 | 显示loading图标，文字可选 | 禁用点击 |
| 禁用 | 灰色，不可交互 | 无响应 |

#### 1.2.2 操作按钮加载态

**触发场景**：
- 表单提交
- 状态切换操作
- 异步请求操作

**交互行为**：
```javascript
// 点击后立即进入加载态
loading.value = true

// 操作完成后恢复
loading.value = false

// 禁止重复点击
<el-button :loading="loading" @click="handleSubmit">确定</el-button>
```

## 二、危险操作规范

### 2.1 危险操作定义

| 操作类型 | 操作名称 | 风险等级 |
|----------|----------|----------|

## 三、状态同步规范

### 3.1 自动刷新机制

| 数据类型 | 刷新间隔 | 刷新方式 |
|----------|----------|----------|
| 主机状态 | 30秒 | 轮询 |
| 实例状态 | 30秒 | 轮询 |
| 资源使用率 | 30秒 | 轮询 |
| 在线玩家数 | 30秒 | 轮询 |
| 操作日志 | 不自动刷新 | 手动刷新 |

### 3.2 操作后刷新

| 操作类型 | 刷新范围 |
|----------|----------|
| 新增主机 | 刷新主机列表 |
| 删除主机 | 刷新主机列表 + 实例列表 |
| 部署实例 | 刷新实例列表 |
| 启停实例 | 刷新当前实例状态 |
| 修改配置 | 不刷新，提示重启生效 |

### 3.3 状态一致性保证

```
用户操作 → 立即显示加载态 → 后端执行 → 返回结果 → 更新UI状态
                ↓
           乐观更新（可选）
```

**乐观更新场景**：
- 启停实例：立即更新状态为"处理中"
- 删除操作：立即从列表移除，失败后恢复

## 四、异常处理规范

### 4.1 网络异常处理

| 异常类型 | 处理方式 | 用户提示 |
|----------|----------|----------|
| 请求超时 | 自动重试3次 | "网络超时，正在重试..." |
| 网络断开 | 显示断开提示 | "网络连接已断开，请检查网络" |
| 服务器错误 | 显示错误信息 | "服务器错误，请稍后重试" |

### 4.2 业务异常处理

| 异常类型 | 处理方式 | 用户提示 |
|----------|----------|----------|
| 主机离线 | 提前拦截 | "目标主机离线，无法执行操作" |
| 端口冲突 | 表单校验拦截 | "端口已被占用，请更换端口" |
| 权限不足 | 显示错误 | "权限不足，无法执行此操作" |
| 资源不足 | 显示错误 | "主机资源不足，无法部署实例" |

### 4.3 错误提示规范

**错误提示必须包含**：
1. 错误类型/位置
2. 错误原因
3. 解决建议（可选）

**示例**：
```
部署失败：主机 Host-A 环境检查未通过
原因：Docker未安装
建议：请先在主机上安装Docker，或选择其他部署方式
```

## 十、插件交互规范

### 10.1 插件交互统一性

插件必须遵循以下交互规范，确保与原生功能无差异：

| 规范项 | 要求 |
|--------|------|
| 弹窗 | 使用主应用封装的弹窗方法 |
| 通知 | 使用ElMessage/ElNotification |
| 加载态 | 使用主应用loading指令 |
| 确认框 | 使用ElMessageBox.confirm |
| 表单校验 | 使用Element Plus表单校验 |

### 10.2 插件操作日志

插件所有操作必须调用主应用日志记录接口：

```javascript
// 记录操作日志
window.$platform.logOperation({
  module: 'L4D2地图管理',
  action: '切换地图',
  target: 'L4D2-01',
  result: 'success'
})
```

### 10.3 插件危险操作

插件危险操作必须遵循主应用二次确认规范：

```javascript
// 使用主应用确认框
window.$platform.confirmDanger({
  title: '删除地图',
  message: '确定要删除地图「xxx」吗？',
  confirmText: '地图名称',
  onConfirm: () => {
    // 执行删除
  }
})
```
