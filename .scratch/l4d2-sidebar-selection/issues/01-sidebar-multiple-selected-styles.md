# 01: L4D2 侧边栏多个菜单同时呈现选中样式

Status: needs-triage
Type: bug
来源: 用户反馈（2026-10-19）

## 现象

求生之路2 插件的侧边栏中，多个菜单项同时呈现类似选中/强调的整行样式。截图中「求生之路2」父级、多个分组标题和「服务器信息」叶子菜单都出现了边框或高亮，用户无法仅凭视觉判断当前真正选中的菜单。

![侧边栏多个菜单同时高亮](../assets/sidebar-multiple-highlight.png)

## 期望

- 同一时刻只高亮当前选中的菜单。
- 当前选中项只有一级叶子菜单；父级菜单和分组标题只表达展开/收起状态，不与选中态共用同一套整行高亮。
- 未选中菜单保持普通状态，不出现看起来可点击选中、但实际不会导航的强调样式。
- 键盘导航、深链接进入、刷新页面后，选中态仍只落在一个正确的叶子菜单上。

## 复现步骤

1. 打开 L4D2 插件管理或相关插件页面。
2. 查看左侧「求生之路2」菜单树。
3. 点击「配置管理」下的「服务器信息」。
4. 观察「求生之路2」父级、「配置管理」分组及其它菜单项是否同时出现高亮/边框。

## 待 triage 确认

- 异常来自主应用侧边栏菜单组件，还是 Wujie 子应用内部菜单叠加？
- 父级菜单是否被设计为“展开即高亮”，还是样式选择器误命中了所有分组？
- 需要统一选中态、展开态、悬停态三套样式，还是只修选中态？
- 刷新页面、直接打开子路由、切回其它插件后，选中态是否保持一致？

## 验收

- [ ] 任意时刻只一个叶子菜单处于选中高亮。
- [ ] 父级菜单只显示展开/收起状态，不显示与选中项相同的整行高亮。
- [ ] 点击不同叶子菜单后，旧选中态及时消失，新选中态正确出现。
- [ ] 刷新页面或直接打开子路由时，选中态仍唯一且正确。
- [ ] 悬停态与选中态有明显区别，不会让用户误以为多个菜单已选中。

## 关联

- 页面：求生之路2 插件侧边栏。
- 规范：侧边栏菜单应复用主应用一致的选中/展开状态，不叠加第二套视觉语义。
- 本 issue 仅记录问题，不包含实现。
