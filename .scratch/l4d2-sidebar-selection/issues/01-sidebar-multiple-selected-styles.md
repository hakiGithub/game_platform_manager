# 01: L4D2 侧边栏多个菜单同时呈现选中样式

Status: resolved
Type: bug
来源: 用户反馈（2026-10-19）

## 现象

求生之路2 插件的侧边栏中，多个菜单项同时呈现类似选中/强调的整行样式。截图中「求生之路2」父级、多个分组标题和「服务器信息」叶子菜单都出现了边框或高亮，用户无法仅凭视觉判断当前真正选中的菜单。

![侧边栏多个菜单同时高亮](../assets/sidebar-multiple-highlight.png)

## 期望

- 同一时刻只高亮当前选中的菜单。
- 当前选中项只有一级叶子菜单；父级菜单和分组标题只表达展开/收起状态，不与选中态共用同一套整行高亮。
- 未选中菜单保持普通状态，不出现看起来可点击选中、但实际不会导航的强调样式。
- 键盘导航、深链接进入、刷新页面后，选中态仍只落在一个正确的叶子菜单上。

## 复现步骤

1. 打开 L4D2 插件管理或相关插件页面。
2. 查看左侧「求生之路2」菜单树。
3. 点击「配置管理」下的「服务器信息」。
4. 观察「求生之路2」父级、「配置管理」分组及其它菜单项是否同时出现高亮/边框。

## 验收

- [x] 任意时刻只一个叶子菜单处于选中高亮。
- [x] 父级菜单只显示展开/收起状态，不显示与选中项相同的整行高亮。
- [x] 点击不同叶子菜单后，旧选中态及时消失，新选中态正确出现。
- [x] 刷新页面或直接打开子路由时，选中态仍唯一且正确。
- [x] 悬停态与选中态有明显区别，不会让用户误以为多个菜单已选中。

## 关联

- 页面：求生之路2 插件侧边栏。
- 规范：侧边栏菜单应复用主应用一致的选中/展开状态，不叠加第二套视觉语义。
- 本 issue 已由 triage 转为可执行说明。

### 2026-10-20 Triage 结论

**分类：** bug
**状态：** ready-for-agent

截图中异常出现在主应用侧边栏，不是 Wujie 子应用内部菜单。叶子 `el-menu-item` 的整行选中样式本身只命中 `.is-active`，但 Element Plus 会给当前叶子的所有祖先 `el-sub-menu` 添加活跃状态，当前主题又为祖先和折叠态写了与选中态接近的背景、边框和阴影，使插件根、分组标题与真正叶子看起来同时被选中。

需要把“导航选中”“祖先展开关系”“鼠标悬停”定义为三种可区分的视觉语义。祖先是导航链路时可以有颜色提示，但不得复用叶子的整行背景、边框和左侧选中条。

## Agent Brief

**Category:** bug
**Summary:** 侧边栏仅让唯一叶子菜单显示整行选中态，父级和分组只表达展开及祖先关系

**Current behavior:**

进入 L4D2 插件页面后，插件根、配置管理分组和当前叶子同时出现类似整行选中的蓝色背景、边框或阴影。Element Plus 为当前叶子的祖先 `el-sub-menu` 设置了活跃状态，现有侧边栏样式又对祖先与折叠态做了重叠强调，导致用户无法仅凭视觉判断唯一当前页面。

**Desired behavior:**

任意时刻只有当前路由对应的一个叶子 `el-menu-item` 使用整行选中样式，包括背景、边框和选中条。插件根与分组标题只表现展开/收起及必要的祖先导航关系；它们不能使用与叶子相同的整行强调。悬停态与选中态明显不同。折叠模式下仍保持唯一选中，不把祖先的子菜单活跃状态放大成选中态。

刷新、深链进入、切换分组、切换到其他插件以及点击重复菜单后，选中项都应唯一且与当前路由一致。路由不在插件树内时，不能残留上一个插件的叶子选中。

**Key interfaces:**

- 侧边栏的 `activeMenu` 计算值：必须返回唯一叶子 index，而不是父级或分组 index。
- `el-menu` 的 `default-active` 与路由同步：保持当前路由唯一映射。
- 叶子 `.el-menu-item.is-active` 样式与祖先 `.el-sub-menu.is-active > .el-sub-menu__title` 样式：视觉规则必须分离。
- 折叠态下菜单项与子菜单标题的选中样式：不得形成多个整行高亮。
- `handleSelect()`：只有叶子导航触发选中；父级点击只展开/收起。

**Acceptance criteria:**

- [ ] 任意插件页面中，DOM 里最多一个叶子菜单具有完整选中背景、边框和选中条。
- [ ] 插件根和分组标题不出现与叶子相同的整行选中样式；展开态和祖先导航关系仍可识别。
- [ ] 点击不同叶子后旧叶子立即取消选中，新叶子成为唯一选中项。
- [ ] 刷新、直接打开插件子路由、切换插件、切换分组后，选中项仍唯一且与当前路由匹配。
- [ ] 悬停与选中在颜色、背景或边框上明显不同；悬停不会触发选中语义。
- [ ] 折叠态测试确认只有唯一叶子或明确的当前节点被强调，祖先不会叠成多个选中块。
- [ ] 添加组件测试或 Playwright 回归，断言当前路由下 `is-active` 叶子数量为 1，并验证深链与切换场景。

**Out of scope:**

- 重构主应用路由表或插件菜单声明格式。
- 修改 Wujie 子应用内部导航样式。
- 改动画布、间距或其他与选中/展开语义无关的侧边栏视觉。
