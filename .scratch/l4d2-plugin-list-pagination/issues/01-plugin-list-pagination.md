# 01: L4D2 插件管理各列表缺少分页

Status: needs-triage
Type: enhancement
来源: 用户反馈（2026-10-19）

## 现象

L4D2 插件管理页下的各个插件列表菜单均未提供分页处理。数据量增加后，用户只能在一个持续增长的列表中查找和操作插件，缺少总数、页码、每页数量以及前后翻页能力。

复现入口：

- 打开 `http://localhost:3002/extensions/app/l4d2/plugins?instanceId=97`
- 查看插件管理页下的各个列表菜单

## 期望

插件管理页下所有需要展示插件集合的菜单都能分页浏览：

- 展示总条数、当前页和每页数量。
- 支持上一页、下一页及直接切换页码。
- 支持切换每页条数。
- 在数据量不超过一页时仍保持布局稳定，不出现误导性的空分页区域。

## 待 triage 确认

- “所有菜单”具体覆盖已启用插件、内置插件、远端仓库等哪些列表？
- 分页由前端对已加载数据切片，还是后端接口返回分页结果？
- 搜索、筛选、刷新和安装状态变化后，是否需要保留当前页或回到第一页？
- 各列表的默认每页数量是否统一？
- 是否存在必须一次展示全部数据才能完成的批量选择操作？

## 验收

- [ ] 插件管理页下所有适用的列表均具备一致的分页交互。
- [ ] 用户能明确看到总量、当前页和每页数量。
- [ ] 翻页、切换每页数量后列表内容正确更新。
- [ ] 搜索或筛选不会只作用于当前页而遗漏其他页的数据。
- [ ] 单页数据、零数据和加载失败状态有清晰展示。
