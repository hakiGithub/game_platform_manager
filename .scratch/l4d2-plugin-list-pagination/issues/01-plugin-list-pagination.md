# 01: L4D2 插件管理各列表缺少分页

Status: done
Type: enhancement
来源: 用户反馈（2026-10-19）

## 现象

L4D2 插件管理页下的各个插件列表菜单均未提供分页处理。数据量增加后，用户只能在一个持续增长的列表中查找和操作插件，缺少总数、页码、每页数量以及前后翻页能力。

复现入口：

- 打开 `http://localhost:3002/extensions/app/l4d2/plugins?instanceId=97`
- 查看插件管理页下的各个列表菜单

## 期望

插件管理页下所有需要展示插件集合的菜单都能分页浏览：

- 展示总条数、当前页和每页数量。
- 支持上一页、下一页及直接切换页码。
- 支持切换每页条数。
- 在数据量不超过一页时仍保持布局稳定，不出现误导性的空分页区域。

## 验收

- [x] 插件管理页下所有适用的列表均具备一致的分页交互。
- [x] 用户能明确看到总量、当前页和每页数量。
- [x] 翻页、切换每页数量后列表内容正确更新。
- [x] 搜索或筛选不会只作用于当前页而遗漏其他页的数据。
- [x] 单页数据、零数据和加载失败状态有清晰展示。

## 关联

- 页面入口：L4D2 插件管理页。
- 术语遵循 `CONTEXT.md` 的插件市场与插件列表相关领域词汇。

范围锁定为插件管理页的三个集合：

## Agent Brief

**Category:** enhancement
**Summary:** 为已安装、内置市场和远端仓库三个插件列表提供一致的分页与筛选语义

**Current behavior:**

插件管理页的三个插件集合一次性渲染全部记录。远端仓库接口接受 `page`/`size` 但只返回当前页数组，调用方拿不到总数；已安装与内置列表没有分页参数。搜索结果可能只在当前已加载数据上过滤，数据量增长后无法可靠浏览，也无法判断当前页与总量。

**Desired behavior:**

三个列表都显示总数、当前页、每页数量和页码导航，支持切换每页数量。单页或零数据时保持稳定布局，空状态与加载失败状态清楚。搜索、分类、安装状态和刷新对完整数据集生效，不能只过滤当前页。筛选条件变化时回到第一页；单纯翻页时保留筛选条件。刷新后如果当前页已越界，应回到最后一个有效页。批量启用/禁用只作用于用户在当前页显式勾选的插件，并在翻页后清空选择，避免隐形跨页批量操作。

分页查询必须返回总数和当前页记录。接口对页码小于 1、页大小越界和超出末页给出确定行为，前端不应依赖后端静默返回空页。三个列表可以使用一致默认值，但各自保留独立分页状态，互不串页。

**Key interfaces:**

- `PluginStoreController.list()`：当前接收 `page`/`size` 却返回 `List`；应返回带总数、当前页、页大小和记录的分页结构。
- 已安装插件列表接口：当前返回全量集合；需要增加查询分页契约，或由服务层返回包含总数的稳定分页结果。
- 内置插件列表接口：当前返回本地清单全量集合；与已安装和远端列表使用一致的页参数和响应结构。
- `pluginManageApi.list()`、`pluginManageApi.listBuiltin()`、`pluginStoreApi.list()`：补齐分页参数及分页响应类型。
- 三个插件列表组件：分别维护查询状态；搜索/筛选变化重置页码，刷新校验越界，翻页清空选择。

**Acceptance criteria:**

- [x] 三个列表都可见总数、当前页和每页数量，并支持前后翻页与直接选页。
- [x] 切换每页数量后重新请求正确页，列表内容与分页信息一致。
- [x] 搜索、分类和安装状态筛选对完整数据集生效，不局限于当前页。
- [x] 筛选变化回到第一页；删除、安装或刷新导致当前页越界时落到最后有效页，并显示结果。
- [x] 零数据、单页数据和请求失败状态布局稳定，不出现误导性分页区域。
- [x] 已安装列表翻页后清空选择，批量启用/禁用请求只包含当前页已勾选的插件。
- [x] 三个列表的分页状态互不影响；来回切换菜单后不会把页码或筛选串到另一个列表。
- [x] 后端测试覆盖分页元数据、越界页和筛选后总数；前端测试覆盖翻页、页大小变化、筛选重置页码和选择清空。

**Out of scope:**

- 改变插件安装、启用、禁用或远端仓库下载的业务语义。
- 支持跨页选择或全量选择；当前批量操作明确限定为当前页。
- 重新设计插件管理页的导航结构或插件分类体系。
- 为任务中心、日志等其他列表补分页。

### 2026-10-20 实施结果

**实现**

- 已安装、内置市场、远端仓库三个列表统一使用服务端分页响应，展示总数、当前页、每页数量和页码导航。
- 搜索、分类、安装状态和平台条件均在服务端查询完整集合；筛选变化重置到第 1 页。
- 已安装列表翻页或切换页大小会清空表格选择，批量操作只针对当前页的显式选择。
- 页大小限制为 `1..100`；超出末页的请求会返回最后一个有效页。
- 新增已安装插件名称全集和远端仓库分类接口，避免分页后丢失筛选选项。

**验证**

- 后端目标测试通过：`PluginStoreControllerTest`、`PluginManageControllerTest`。
- 前端相关测试 16/16 通过：分页 composable、API 契约和插件名称匹配。
- 插件前端生产构建通过。
