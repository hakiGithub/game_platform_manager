# L4D2 已安装插件启用状态无法回读

## 背景

用户在已安装插件页面点击单插件“启用”或“批量启用”后，接口返回成功，
但刷新列表仍全部显示“已禁用”。

真实实例复现发现 `.enabled_plugins.yaml` 中历史中文插件名已损坏为问号，
启用新插件时读取旧清单后原样写回。列表按插件目录名匹配清单时因此失配，
所有受影响的插件都回落为禁用状态。

## 目标

- 启用后的插件状态可稳定写入并回读。
- 中文插件名在清单读写过程中不因平台默认字符集而损坏。
- 单插件启用与批量启用共用同一条可靠的状态登记路径。
- 对已经损坏的清单，能够从 `plugins_store` 目录恢复明确的插件名对应关系，
  避免升级后继续显示全量禁用。
- 不改变启用/禁用的文件复制语义，不引入新的前端交互。

## 验收

- 中文名插件启用后，`list` 返回 `status=enabled` 和正确的 `enableTime`。
- 批量启用后，每个成功插件都能回读为启用。
- `.enabled_plugins.yaml` 以 UTF-8 读写。
- 历史清单中的问号名称不会再覆盖可识别的插件目录名。
- 定向服务测试和控制器测试通过。
- 构建、热部署后通过真实实例接口验证。
