# 01: 插件前端构建与开发服务器并发时 components.d.ts 写入失败

Status: done
Type: bug
来源: L4D2 插件配置编辑器构建验证（2026-10-20）

## 现象

在插件前端开发服务器保持运行时执行生产构建，`unplugin-vue-components` 重写 `src/components.d.ts` 会失败：

```text
UNKNOWN: unknown error, open ...\src\components.d.ts
errno: -4094
```

同一工作区随后使用关闭组件声明生成、并改用独立输出目录的临时 Vite 配置可以成功打包。标准 `npm run build` 因此不能在“开发服务器运行期间执行构建/部署”的常见工作流中稳定通过。

## 复现路径

1. 在 `backend/plugin-l4d2/frontend` 启动开发服务器。
2. 保持开发服务器运行。
3. 执行 `npm run build`。

## 期望

- 开发服务器运行时也能完成生产构建和热部署。
- 默认开发模式仍可生成组件类型声明。
- CI/部署构建可以显式关闭声明文件写入，避免多个 Vite 进程同时改同一文件。
- 关闭声明写入不得影响实际 UI 产物、路由资源或运行时组件注册。

## 验收

- [x] 提供明确的构建环境开关，使部署构建不写 `components.d.ts`。
- [x] 默认开发行为保持现有类型声明生成能力。
- [x] 开发服务器保持运行时，标准生产构建可重复通过。
- [x] 构建产物包含本次配置编辑器页面与更新后的插件前端资源。
- [x] 文档或构建脚本说明何时关闭声明写入。
