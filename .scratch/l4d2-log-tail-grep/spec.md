# L4D2 日志查看与远端 grep

## 目标

修复日志文件点击后不加载的问题；初始内容通过远端 `tail -n` 获取，搜索通过远端
`tail -n | grep -F` 执行，避免把整份日志下载到浏览器或平台内存。

## 范围

- 日志文件选择后立即显示正确文件名并加载末尾内容。
- 搜索输入支持管道 grep 语义，默认固定字符串匹配。
- 后端提供实例感知的语义化 tail/grep 能力，自动路由 Native SSH 与 Docker。
- 前端轮询新内容时复用相同读取链路，并防止旧请求覆盖新文件。

## 非目标

- 不开放任意 shell 命令。
- 不实现正则表达式编辑器；首版使用 `grep -F` 固定字符串。
- 不改变 SourceMod 日志文件命名规则。
