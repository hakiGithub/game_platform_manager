# 04: 部分 L4D2 插件配置项仍缺少描述

Status: resolved
Type: bug
来源: 用户反馈（2026-10-20）

## 现象

用户反馈“求生之路2部分插件的配置描述还是没有”。现有配置编辑器已能解析并展示 `description`，但真实插件配置中仍有部分配置项在页面显示 `-`。

## 已知数据入口

- 实例：97
- 入口：L4D2 插件管理页的配置弹窗
- 相关接口：`GET /api/plugin/l4d2/plugin-config/get?instanceId=97&pluginName=...`
- 现有实现：`SourceModCfgParser` 从 cfg 注释中解析描述，`PluginConfig.vue` 以 `row.description || '-'` 展示。

## 需要确认

- 哪些插件/哪些 cfg 文件/哪些 key 仍无描述。
- 对应 cfg 原文是否存在可读注释；若存在，确认解析器是否漏掉该注释格式。
- 若 cfg 原文本身没有描述，确认产品期望是显示空值、根据 CVAR 元数据补充，还是标记“无说明”。

## 期望

- 对存在可读注释的配置项，描述列必须展示注释内容。
- 对确实没有描述的配置项，保持清晰降级，不把解析失败伪装成“无说明”。
- 覆盖至少一个真实插件 cfg 的回归样例，防止后续解析器改动再次丢失描述。

### 2026-10-20 实施与真实验证

**根因**

SourceMod cfgbuilder 生成的 cfg 在描述和 `Default/Minimum/Maximum` 之间使用
独立一行 `// -`。原解析器遇到 `-` 就停止向上扫描，导致描述永远为空。

**实现**

- `SourceModCfgParser` 遇到独立 `// -` 时跳过并继续扫描描述块。
- 描述清理移除独立 `-` 行，不把分隔符显示给用户。
- 新增精确回归用例，覆盖
  `描述 + // - + Default + Minimum + Maximum + key`。

**真实验证**

- `SourceModCfgParserTest`：12/12 通过。
