# 15 — 受管启动只打包插件 JAR，不构建插件 UI，导致插件资源 404

Status: done
Type: bug
来源: 2026-10-20 UI E2E 受管模式验证

## 现象

在独立 worktree 中通过受管模式启动平台时，`backend/scripts/rebuild-restart.ps1`
调用 `Build-Plugins` 只执行 Maven 打包，没有构建 `plugin-l4d2/frontend`。
生成的插件 JAR：

```text
backend/plugin-l4d2/plugin-l4d2-core/target/plugin-l4d2-core-1.0.0-SNAPSHOT.jar
```

大小约 794 KB、327 个 entry，不包含 `ui/index.html`。后端启动后：

```text
GET /api/pf4j/plugin/l4d2/ui/index.html
```

返回 404，主应用 Wujie 插件入口无法加载。已有完整插件 JAR 约 124 MB、
535 个 entry，包含 `ui/index.html` 与 `ui/assets/*`，因此问题只在构建路径，
不是 PF4J 资源路由本身。

## 复现路径

1. 在未构建插件前端的 worktree 中执行
   `backend/scripts/rebuild-restart.ps1`。
2. 等待后端就绪，查询插件 JAR 内容。
3. 请求 `/api/pf4j/plugin/l4d2/ui/index.html`。

## 期望

- `rebuild-restart.ps1` 在打包插件 JAR 前构建插件前端，构建失败必须中止启动，
  不得部署缺少 UI 的 JAR。
- 插件 JAR 必须包含 `ui/index.html` 和构建后的 `ui/assets/*`。
- 部署后 `/api/pf4j/plugin/l4d2/ui/index.html` 返回 200，插件入口可正常加载。
- 仅改后端且显式使用 `-SkipPlugins` 时可跳过插件前端构建和 JAR 打包。
