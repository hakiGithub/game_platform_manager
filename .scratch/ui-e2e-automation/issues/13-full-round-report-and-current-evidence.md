# 13 — 整轮 runner 的 HTML 报告契约与当前七组清单证据不一致

Status: done
Type: bug
来源: 2026-10-20 集成分支 UI E2E 独立验收

## 现象

当前 `frontend/e2e/runner.mjs` 的整轮编排包含七个分组：

1. 冒烟与导航
2. 无主机页面组
3. 主机纳管
4. 容器认领
5. 实例生命周期 l4d2
6. 插件子应用 l4d2
7. dst/sdtd 演练腿

但工程 README 和票据 09 的最终 PASS 记录仍描述“六组”，且票据 09 记录的
各组用例数（9/10/5/6/6/4）早于后来合入的容器认领、Steam302、RCON 深度操作、
插件列表分页、侧边栏选中和插件次要页面用例。当前 Playwright 清单为
`80 tests in 18 files`，而票据 09 的旧证据无法独立证明这 80 条在当前
integration tip 上都已纳入同一轮编排。

另一个独立问题是整轮 runner 对每个分组强制执行 `--reporter=list`：

```js
const r = runPlaywright([...group.paths, "--reporter=list"], {
  stdio: ["ignore", "pipe", "inherit"],
  encoding: "utf8",
});
```

Playwright 命令行的 `--reporter=list` 会覆盖 `playwright.config.js` 中的
`html` reporter，因此整轮结束时 runner 仍输出“HTML 报告: npm run e2e:report”，
但不会生成 `frontend/e2e/.report/index.html`。定向附着运行不使用该覆盖时，
同一配置会正常生成 HTML 报告。

## 复现路径

1. 确认平台前后端可用，且本 worktree 已执行 `npm ci`。
2. 运行：

   ```powershell
   cd frontend
   $env:E2E_BASE_URL='http://127.0.0.1:3002'
   $env:E2E_BACKEND_URL='http://127.0.0.1:8080'
   npm run e2e -- --attach e2e/infra e2e/main-app/auth/login.spec.js --reporter=list
   ```

3. 观察运行以 PASS 结束，但 `frontend/e2e/.report/index.html` 不存在。
4. 去掉 `--reporter=list` 重跑同一子集，`frontend/e2e/.report/index.html` 正常生成。
