# 14 — 缺少主机凭据时，部分 live 插件用例未显式 SKIP 而失败

Status: done
Type: bug
来源: 2026-10-20 集成分支 UI E2E 独立验收（附着模式整轮，无 `e2e/.env.local`）

## 现象

在无牺牲主机凭据的环境执行：

```powershell
cd frontend
$env:E2E_BASE_URL='http://127.0.0.1:3002'
$env:E2E_BACKEND_URL='http://127.0.0.1:8080'
node e2e/runner.mjs --attach --round
```

整轮结果为 `19 passed / 3 failed / 58 skipped`，其中三条失败均来自依赖真实
L4D2 实例的 live 用例，而不是由 `skipWithoutTestHost()` 或等价门控显式跳过：

1. `main-app/plugins/plugin-list-pagination-live.spec.js` 固定访问实例 `97`，
   页面 `.plugins-page` 未渲染，`waitForResponse` 超时。
2. `main-app/plugins/plugins.spec.js` 的“进入工作区”分支固定按实例状态进入
   dashboard，但目标实例的插件页面不可用，`.dashboard-page` 超时。
3. `plugins/l4d2/plugin-config-multifile-live.spec.js` 固定访问实例 `97`，
   `.plugin-config-page` 超时。

同一轮中的 `rcon-live-ops.spec.js` 已通过
`E2E_L4D2_LIVE_INSTANCE_ID` 显式跳过；其他真实主机用例通过
`skipWithoutTestHost()` 跳过。上述三条用例的固定实例 ID 与未门控前置使
“无主机环境整轮 PASS（除显式 SKIP 外）”契约不成立。

## 复现路径

1. 不提供 `frontend/e2e/.env.local`，不设置 `E2E_L4D2_LIVE_INSTANCE_ID`。
2. 保持平台前后端可访问，并按上方命令执行附着整轮。
3. 观察无主机页面组和插件子应用组中的三条失败，而不是显式 SKIP。

## 期望
