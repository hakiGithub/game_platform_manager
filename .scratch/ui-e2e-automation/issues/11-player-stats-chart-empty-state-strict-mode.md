# 11 — 玩家统计趋势断言在图表与空态并存时触发 strict mode

Status: done
Type: bug
来源: 2026-10-20 附着模式 E2E 整轮执行（plugin-subapp.spec.js）

## 现象

`frontend/e2e/plugins/l4d2/plugin-subapp.spec.js` 的
`玩家统计页可切换到游玩时长并展示格式校验` 用例使用 `.or()` 同时接受
`.chart` 和“暂无趋势数据”空态：

```js
await expect(
  page
    .locator(".chart")
    .first()
    .or(page.getByText("暂无趋势数据", { exact: true })),
).toBeVisible({ timeout: 30_000 });
```

当页面同时存在 `.chart` 元素和空态文本时，组合定位器命中两个元素，
Playwright strict mode 直接失败。失败发生在 serial 文件中段，导致其后的
6 条用例 skipped、21 条用例 did not run，整轮无法继续。

## 复现路径

1. 平台前后端运行中，L4D2 实例 97 已由共享 fixture 部署。
2. 运行 `plugin-subapp.spec.js` 中的
   `玩家统计页可切换到游玩时长并展示格式校验`。
3. 趋势区域同时渲染图表容器与“暂无趋势数据”文本，`.or()` 定位器匹配两个元素。

## 期望
