# L4D2 性能监控临时文件存储

## 目标

将 L4D2 性能监控历史从扩展资源表迁移到插件本地临时文件。采集时流式追加，
查询时流式扫描并按目标点数聚合，不将完整历史加载到内存，也不再写入数据库。

## 范围

- 保留 `/monitor/status`、`/monitor/history`、`/monitor/config` 的现有响应契约。
- 监控配置中的历史开关继续控制是否写临时文件。
- 保留时长到期后清理本地临时文件。
- 实例删除时清理对应文件。

## 非目标

- 不修改前端图表字段和布局。
- 不迁移或保留数据库中的历史监控数据。
- 不新增跨主机采集能力。
