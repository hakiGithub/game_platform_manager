# 01: 性能监控历史改用临时文件

Status: ready-for-agent
Type: enhancement
来源: 用户反馈（2026-10-20）

## 现象

性能监控每秒采集一次，当前通过 `ExtensionClient.create` 写入扩展资源表。历史查询会
从表中读取最多 10000 条记录，再在内存中降采样。数据量增长后既增加数据库写入压力，
也增加查询时的内存占用。

## 期望

- 采集结果追加写入插件本地临时文件，不落扩展资源表。
- 历史查询流式读取文件，按查询时间范围和目标桶数直接聚合，不加载完整历史。
- 临时文件按实例隔离，保留时长到期后清理。
- 实例删除时清理对应文件。
- 保留现有监控 API 和前端图表契约。

## 验收

- [ ] 采集不再调用 `ExtensionClient.create`。
- [ ] 历史查询不再调用 `ExtensionClient.list` / `listAll`。
- [ ] NDJSON 文件按实例写入，查询结果按时间升序返回。
- [ ] 超过降采样阈值时结果不超过 `downsampleTo`。
- [ ] 过期文件和实例删除时文件可被清理。
- [ ] 监控相关单元测试、插件构建通过。
