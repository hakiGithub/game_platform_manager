# 01: Workshop 解析在未配置 Steam API Key 时返回通用系统异常

Status: resolved
Type: bug
来源: 用户反馈（2026-10-21）

## 现象

请求：

```http
POST /api/plugin/l4d2/download/parse-workshop
Content-Type: application/json

{"url":"https://steamcommunity.com/sharedfiles/filedetails/?id=3560886237"}
```

响应：

```json
{"code":500,"message":"系统异常,请联系管理员","data":null}
```

日志中的真实异常：

```text
L4D2PluginException: STEAM_API_KEY 未配置
at SteamApiClient.getPublishedFileDetails(SteamApiClient.java:79)
```

## 根因

- `SteamApiClient` 只调用要求 Key 的 `IPublishedFileService/GetDetails/v1`。
- 当前部署没有配置 `plugin.l4d2.steam.api-key`。
- `DownloadController` 未把 `L4D2PluginException` 转换为宿主可识别的
  `BusinessException`，最终落到通用 500 处理器。

已验证 Steam 公开接口 `ISteamRemoteStorage/GetPublishedFileDetails/v1`
无需 Key，且条目 `3560886237` 可返回完整文件信息。

## 期望

- 单文件 Workshop 解析优先使用无需 Key 的公开接口。
- 公开接口不可用或需要集合展开时，回退到现有带 Key 接口。
- 控制器把插件业务失败转换为可读错误，不再返回通用“系统异常”。
- 不改变现有接口路径和响应字段。
